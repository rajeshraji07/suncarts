SunCart sample images
=====================
Each food photo is a separate file in this folder. To use a better photo,
save it as WebP with the SAME file name and replace the old file.
(To use JPG or PNG instead, change 'images/'+k+'.webp' in the PHOTOS line of index.html.)

Tips: about 420 x 280 px, landscape, under 40 KB, dish centred on the plate.
